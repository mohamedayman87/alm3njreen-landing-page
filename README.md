# alm3njreen

The website for a travel agency that sells curated trips. Team Alm3njreen built it as a static site, so it's just HTML and CSS. No framework, no JavaScript, nothing to install.

**Live site:** add your GitHub Pages link here

## What's on the page

- A full-screen hero with the brand's pitch and two calls to action
- Handpicked packages (Spain, Australia, Egypt) on cards whose details slide up on hover
- An about section: who we are and why people book with us
- A destinations grid: Amazon Forest, New Zealand, London, Europe, Africa
- A "why us" block covering customized packages, adventure tours and luxury vacations
- A footer with a booking call to action, quick links, contact details and social links

The menu scrolls within the page, and the layout adjusts for tablets and phones.

## Built with

HTML5, CSS3, Font Awesome 7 for the icons, and Google Fonts (Playfair Display, Roboto, Ultra). The brand orange is the same everywhere, so changing the color means a quick find-and-replace in `home_style.css`.

## Run it locally

Clone the repo, make sure the `images/` folder sits next to `index.html`, and open the file in a browser.

## Files

- `index.html`: all the content and structure
- `home_style.css`: styles and responsive rules
- `images/`: photos and illustrations
